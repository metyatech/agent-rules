# Syllabus Authoring

- Syllabus edits MUST preserve the course's actual taught sequence and current progress.
- A syllabus is the planned schedule. Do not automatically change it to match
  actual progress or as part of quiz authoring; record teacher-confirmed taught
  scope separately in the course year's `progress.yaml`.
- Existing free-text lesson notes are references only. Do not automatically
  migrate them to progress records or treat them as confirmation that scope was
  taught.
- When adjusting a syllabus to actual progress, use concrete lesson numbers,
  textbook pages, material files, or user-provided progress facts.
- Do not infer actual progress from general course knowledge when the user
  provides specific progress information.
- If a syllabus change shifts assessment scope, report the affected
  quiz/exam/course-docs repositories so they can be updated in a separate task.
- Syllabus entries SHOULD describe lesson scope in stable material terms rather
  than one-off classroom events.
- Do not add a separate material `type` field unless the user explicitly
  requests one.
